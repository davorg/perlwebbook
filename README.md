perlwebbook
===========

A book. About Perl. And the Web.

http://perlwebbook.com/

This repository contains an unfinished manuscript and supporting Perl examples.
The book is assembled from Markdown chapters into EPUB, with optional MOBI and
PDF conversions.

* [Repository findings](REPOSITORY.md): structure, manuscript status, example
  applications, and verified build/test limitations.
* [Build instructions](BUILD.md): the original ebook conversion instructions;
  see the findings for compatibility issues with the current environment.
